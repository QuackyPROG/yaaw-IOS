# Apple design expertise

Use current Apple HIG when a ticket changes UI. Prefer familiar hierarchy, standard navigation, sheets/alerts/menus/toolbars/search, system colors/typography, safe areas, dark mode, SF Symbols, useful haptics, and platform-standard state handling.

Liquid Glass belongs primarily to navigation and controls above content. Do not turn every card/background into glass. Prefer native-backed components when stable and suitable. Record beta/unstable API risk explicitly.
